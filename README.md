## 🚀 Proyectos Destacados

### **SegundaJugada** — *Plataforma Web de Compraventa*
*`[Stack: HTML5, CSS3, JavaScript, PHP, MySQL]`* | [Ver Código](https://github.com/danisatorre/SegundaJugada-POO)
* Plataforma web inspirada en aplicaciones de venta de segunda mano.
* Iniciado durante el 1º curso de DAW y ampliado de forma autónoma incorporando Programación Orientada a Objetos (POO).
* Implementación de autenticación mediante **JWT** y gestión optimizada de consultas SQL.

### **F1-Tracker** — *Análisis y Visualización de Datos de F1*
*`[Stack: PHP, JavaScript, Node.js, HTML5, CSS3]`* | [Ver Código](https://github.com/danisatorre/F1-Tracker) *(En desarrollo)*
* Aplicación para la visualización en tiempo real de métricas y datos de Fórmula 1.
* Basado en un fork de la API [f1-livetiming-api](https://github.com/julesr0y/f1-livetiming-api).
* Consumo y procesamiento de datos en el backend para su posterior renderizado dinámico en el cliente.
